RegEngine is a RAG engine built by Team Nova RRMV.

It allows users to upload documents like PDFs, Word files, and text files.
The system reads these documents and breaks them into small chunks.
Each chunk is converted into a vector (a list of numbers) using embeddings.
These vectors are stored in Qdrant, a vector database.

When a user asks a question, the system finds the most similar chunks.
It then uses an LLM to generate an answer based on those chunks.
This is called Retrieval-Augmented Generation (RAG).

The system is built with Python, FastAPI, Qdrant, and Streamlit.
It runs in Docker for easy deployment.
